1. Introduction to CSS Animations

CSS animations allow us to change the appearance and position of HTML elements over time without using JavaScript.

We use animations to create movement, loading effects, attention-grabbing elements, transitions between visual states, and interactive website experiences.

Animation vs Transition

A transition usually changes an element from one state to another when an event occurs, such as hovering over a button.

An animation can run automatically, repeat several times, move through multiple stages, and be controlled with CSS.

2. CSS Transitions

CSS transitions allow us to control how smoothly an element changes from one CSS property value to another.

Important Transition Properties

  • transition-property: The property to animate.
  • transition-duration: How long the change takes.
  • transition-timing-function: The speed pattern.
  • transition-delay: How long to wait before starting.
  • transition: Shorthand for the transition properties.

3. CSS Transformations

The transform property changes an element's position, size, rotation, or shape without changing the normal layout space it occupies.

Common Transform Functions

  • translate(): Moves an element.
  • scale(): Increases or decreases its size.
  • rotate(): Rotates an element.
  • skew(): Slants an element.
  • transform-origin: Changes the transformation point.

4. CSS Keyframe Animations

The @keyframes rule allows us to define the stages of an animation. We can specify what an element should look like at the beginning, middle, and end of an animation.

Using from and to

The from keyword represents the beginning of an animation, while to represents its ending.

Using Percentages

Percentages allow us to define multiple stages in one animation. For example, 0%, 50%, and 100%.

5. CSS Animation Properties

CSS provides several properties that control how an animation behaves.

  • animation-name: Selects the @keyframes animation.
  • animation-duration: Sets its running time.
  • animation-timing-function: Controls its speed pattern.
  • animation-delay: Delays its starting time.
  • animation-iteration-count: Sets how many times it runs.
  • animation-direction: Controls its direction.
  • animation-fill-mode: Controls styles before or after it runs.
  • animation-play-state: Pauses or runs an animation.
  • animation: Shorthand for animation properties.

6. Animation Timing Functions

Timing functions determine how an animation accelerates and slows down while it runs.

  • linear: Moves at a constant speed.
  • ease: Starts slowly, speeds up, then slows down.
  • ease-in: Starts slowly.
  • ease-out: Ends slowly.
  • ease-in-out: Starts and ends slowly.
  • steps(): Moves in defined steps instead of smoothly.
  • cubic-bezier(): Creates a custom speed curve.
